# ShortFlix — เว็บไซต์ดูซีรีส์สั้นแนวตั้ง (Vertical Drama)

แพลตฟอร์มรับชมซีรีส์แนวตั้ง (Short Drama / Mini Series) สไตล์ TikTok/ReelShort/DramaBox โดยเฉพาะ
**ไม่ต้อง Login / ไม่ต้อง Register** — เปิดเว็บปุ๊บ เลือกดูได้ทันที!

---

## ⚡ ไฮไลท์สำคัญ & ระบบประหยัดโควตา (Requests Saver)

เนื่องจากโควตาฟรีของ DramaBos มีจำกัดเพียง **1,000 requests/เดือน** ระบบนี้จึงถูกออกแบบมาเพื่อ **ประหยัด Requests ให้ได้มากที่สุด 100%**:

1. **ระบบ Cache-First หลายระดับ (Multi-Tier Caching)**:
   - **SQLite Database (`data/cache.db`)**: บันทึกข้อมูลซีรีส์, รายละเอียด, และรายชื่อตอนไว้ในเครื่องนาน **30 วัน**
   - **Seed Catalog ในตัว**: มีคลังซีรีส์ยอดนิยมพร้อมรูปปกและข้อมูลครบถ้วนในเครื่อง เมื่อเปิดหน้าเว็บจะใช้ **0 requests ทันที**
   - **Stream Cache**: แคชลิงก์สตรีมมิ่งวิดีโอไว้ 12 - 24 ชม. หากเปิดดูตอนเดิมซ้ำ จะไม่เสีย requests เพิ่มเติม
2. **ระบบค้นหาแบบ Debounce 600ms**:
   - ป้องกันการยิง API ทุกตัวอักษรที่พิมพ์
3. **ระบบติดตามโควตาแบบเรียลไทม์ (Live Quota Tracker)**:
   - แสดงแถบสถานะบนหน้าเว็บ: `API: X/1,000 | เซฟ Y% 🛡️`
   - สามารถคลิกเพื่อดูสถิติ Requests ที่เซฟได้ และใส่/เปลี่ยน API Key ได้ทันที

## 🎬 ฟีเจอร์ของเครื่องเล่นวิดีโอ (Vertical Video Player)

- **อัตราส่วนแนวตั้ง 9:16** แบบภาพยนตร์/มือถือ
- รองรับการสตรีมมิ่ง HLS (`.m3u8`) ผ่าน **HLS.js** และไฟล์ MP4
- **การควบคุมที่สะดวก**:
  - กด Spacebar หรือแตะหน้าจอ: เล่น/หยุด
  - ปุ่มลอย และปุ่มลูกศรขึ้น/ลง: เปลี่ยนไปตอนก่อนหน้า / ตอนถัดไป
  - ระบบปัดหน้าจอ (Swipe Up/Down) สำหรับมือถือ
  - ปรับความเร็วการเล่นได้ (1.0x, 1.25x, 1.5x, 2.0x)
  - แถบเลื่อนตอน (Episodes Drawer) คลิกเลือกตอนที่ต้องการได้ทันที
  - ระบบ **เล่นตอนถัดไปอัตโนมัติ (Autoplay Next Episode)**
  - ระบบ **ดูค้างไว้ (Continue Watching)** จดจำตอนที่ดูค้างไว้ให้อัตโนมัติ
